## 🚀 Projects Featured

### Foursight Car Rental Management System

A C console application supporting up to 400 cars, 1,000 customers, and
2,000 rental records via flat-file storage. Features role-based login, a
live dashboard, automated late-fee calculation, barcode generation (via
the `zint` CLI), SMTP email notifications (via `libcurl`), and an
ANSI-colored terminal UI.

**[📁 Source
Code](https://drive.google.com/drive/u/1/folders/1zpuuSNAwoMHz94zhKZpZjiJakFftrMV_)**

### Kape Inato Cafe Management System

A PHP/MySQLi web system built for a local café in Tagbilaran, Bohol. It
combines a customer-facing online ordering platform with an admin
dashboard for inventory, sales analytics, and menu/order management,
powered by a MySQL database.

**[📁 Source
Code](https://drive.google.com/drive/u/1/folders/1C8-FlzOtFIf42h5cdC_Se1Aa4Qq9IAmN)**

### HX-1 Rover --- Autonomous Robot

An ESP32-based autonomous robot supporting Sumobot, Human Following,
Obstacle Avoidance, and Maze Solving modes, controlled through a
smartphone web interface over Wi-Fi. It includes a 4-DOF robotic arm,
dual webcam feed, and an Orange Pi network bridge running a Java
WebSocket server.

**[📁 Source
Code](https://drive.google.com/drive/u/1/folders/19hZF6zZ40hAZUpW-CRD1xhgD6UCs4jMA)**

## 💻 Run Locally

1.  Download or clone the repository.
2.  Open the project folder in **Visual Studio Code**.
3.  Open `index.html` using the **Live Server** extension, or open the
    HTML file directly in a browser.
4.  Test all six pages, the role animation, theme control, navigation,
    links, and responsive behavior.
5.  Check the site at mobile widths and with reduced motion enabled
    before publishing.

No build command is required for a plain HTML/CSS/JavaScript version.
External fonts and icon libraries may require an internet connection.
